# Thiên Đạo Viết Lại — Thanh Khê Demo

Demo Godot 4.6 (Windows, chơi đơn), đồ họa 2D do mã nguồn tự vẽ, không lấy assets game khác.

## Cách lấy EXE
Vào **Actions → Build Windows demo → run thành công mới nhất → Artifacts → ThanhKhe_Demo_Windows**, giải nén rồi chạy **ThanhKhe_Demo.exe**.

## Điều khiển
A/D hoặc mũi tên: di chuyển • Shift: chạy • Space: nhảy • E: nói chuyện/hái cỏ • J hoặc chuột trái: đánh • Giữ R gần Linh Thụ: thiền định • I: nhân vật • H: hướng dẫn • 1–4: chọn Thái Hư / Vạn Pháp / Thiên Đạo / Tán tu sau nhiệm vụ.

## Luồng game
Gặp Tống tiên sinh → nhặt 3 linh thảo → đánh 3 linh thú → thiền định tại Linh Thụ → gặp Thôn trưởng để chọn đạo lộ. Tự động lưu tiến độ cục bộ.

**Trạng thái:** đây là bản thử gameplay, chưa có multiplayer, chưa đủ MMORPG, hệ EXP/SM và mỹ thuật còn phải cân sau khi chơi thử. Mở bằng Godot 4.6 để chỉnh sửa.
